# Terraform Projects

A collection of hands-on infrastructure projects using **Terraform, AWS, Docker, and CI/CD tools**.

This repository focuses on developing practical skills in **Infrastructure as Code (IaC), cloud provisioning, infrastructure automation, and DevOps workflows**.

## Technologies

- **Terraform** – Infrastructure provisioning and management
- **AWS** – Cloud infrastructure and services
- **Docker** – Application containerisation
- **CI/CD** – Automated build and deployment workflows
- **Git & GitHub** – Version control and project management

## Project Objectives

- Provision and manage cloud infrastructure using Terraform.
- Develop reusable and maintainable infrastructure configurations.
- Integrate cloud services with containerised applications.
- Explore CI/CD automation and deployment practices.
- Improve practical troubleshooting and cloud engineering skills.

## Purpose

These projects provide hands-on experience with cloud and DevOps technologies, with an emphasis on building, configuring, and managing infrastructure through code.
